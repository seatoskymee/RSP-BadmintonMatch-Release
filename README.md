## 🎯 주요 기능

- **급수별 랜덤 팀 편성** — A/B급(상위) ↔ C/D급(하위) 자동 매칭으로 공정한 복식 파트너 구성
- **풀리그 대진표 자동 생성** — 모든 팀이 1번씩 대전, 경기 수 제한 가능
- **점수 입력 및 결산** — 경기별 점수 입력(최대 31점), 최종순위 자동 계산
- **누적 통계 저장** — 개인별 승/패/점수 자동 누적 (Room SQLite DB)
- **음성 이름 입력** — 🎙 버튼으로 음성 인식 이름 입력
- **DB 회원 목록 선택** — 등록된 회원 목록에서 이름 선택 적용
- **카카오톡 공유** — 최종순위 이미지를 카카오톡 등 앱으로 공유

---

## 📋 사용 방법

1. 인원수 입력 후 **[확인]**
2. 이름 · 급수(A/B/C/D) 입력
3. 경기 수 확인 · 조정 후 **[대진표 생성]**
4. 팀 편성 애니메이션 확인 → **[확정]**
5. 각 경기 점수 입력
6. **[결산하기]** → 최종 순위 확인 및 공유
